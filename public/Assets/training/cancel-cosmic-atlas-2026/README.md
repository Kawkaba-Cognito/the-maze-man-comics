# Cancellation · Cosmic Atlas

Premium flat 2D object family generated for the Cancellation Task on
2026-08-08. The 33 individual WebP files cover every stable training stimulus
used by Survival, Levels, and Pass n Play. Assessment and Adaptive Threshold
intentionally keep the controlled abstract symbol set.

Source sheets:

- `atlas.png` — original 10-object foundation
- `atlas-fleet.png` — portals, spacecraft, probes, and space hardware
- `atlas-celestial.png` — controlled celestial silhouette variants
- `atlas-relics.png` — asteroid, capsule, and crystal variants

All individual files are normalized to a shared transparent 256×256 canvas by
`scripts/extract-cancel-cosmic-icons.mjs`. The extraction script also removes
detached background texture from generated sheets and applies the planet's
approved optical-centering correction.

Art direction: premium hand-inked cosmic atlas, crisp navy contours,
coral/turquoise/gold/violet/cream palette, restrained flat print texture, no 3D.
The source prompts explicitly prohibited text, logos, trademarks, watermarks,
bevels, extrusion, photorealism, gradients, and cast shadows.

The generated sources used a chroma-key background, removed locally with the
Codex ImageGen skill's `remove_chroma_key.py` helper. No third-party or CC0
asset license is required for this generated family.
